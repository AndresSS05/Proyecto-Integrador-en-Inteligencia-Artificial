# Fuentes del repositorio

Este repositorio fue reorganizado tomando como base dos artefactos principales del trabajo entregado:

1. el **notebook de evaluación de modelos sobre Spider**,
2. el **informe académico en Word/PDF**.

## Qué se hizo con ese material
- Se separó la lógica técnica del notebook en módulos Python.
- Se creó una estructura de proyecto mantenible.
- Se documentaron metodología, alcance, hallazgos y reproducibilidad.
- Se dejó el repositorio preparado para incorporar binarios finales en `reports/final/`.

## Qué conviene subir después
Para dejar el repositorio completamente cerrado a nivel de evidencia final, conviene agregar manualmente:
- PDF final del informe,
- DOCX editable,
- figuras exportadas,
- cualquier presentación final.
